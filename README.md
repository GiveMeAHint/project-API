app.py - основной файл API на Flask. Содержит 5 эндпоинтов: авторизация, список направлений, статистика приема, прогноз для руководства, тренд заявлений. Реализована прогнозная модель методом медианы. 

project.db - база данных SQLite. Включает статические параметры (направления подготовки, комплекты ЕГЭ) и динамические параметры (рождаемость, статистика ЕГЭ, заявления, КЦП) за 2019–2023 годы. 

requirements.txt - список всех зависимостей Python, необходимых для корректной работы API. При установке этих пакетов создается среда, идентичная той, в которой разрабатывался проект.
